Ce fichier s'ouvre directement dans le navigateur. Le CSS et le SVG sont intégrés ici ; les animations sont dans avatar-runtime.js, réutilisable par tous les avatars qui suivent le même contrat (data-state, data-emotion, data-viseme). La voix utilise speechSynthesis du navigateur ; aucun micro n'est nécessaire.
